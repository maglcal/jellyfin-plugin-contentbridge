ContentBridge

把外部内容接口的条目以 .strm 虚拟条目的形式注入媒体库。先把「媒体库根目录」加为 Emby 的混合媒体库，再在这里配置数据源。

提示：如果本页显示异常或按钮点了没反应，请按 Ctrl+F5 强制刷新一次（浏览器缓存了旧页面时会卡住脚本）；若整页空白，请强制刷新后重试，并用 F12 → Console 截图反馈。

生成 .strm / .nfo / 海报的目录，例如 /media/online 或 D:\media\online
多条播放线路时优先选中名称或地址包含此关键词的线路，例如 m3u8
生成代理播放链接时使用的对外地址，例如 http://192.168.1.10:8096 或 https://tv.example.com。留空自动取局域网地址；用域名访问 Emby 时必填
关掉则只生成 .strm，靠 Emby 自己刮削
已存在的海报不会重复下载
同步时删除数据源上已不存在的条目（默认关，避免误删）

自动同步

与 控制台 → 计划任务 → 「同步外部内容源」 是同一份设置，在这里改立即生效，不用再去计划任务里找。选「仅手动」则只在点「立即同步」时运行
