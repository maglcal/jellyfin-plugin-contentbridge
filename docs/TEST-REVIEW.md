# ContentBridge v0.3.0.2 测试审核清单

> 分支测试版本 `v0.3.0.2`（分支 `v0.3.0.1`）——在 v0.3.0.1 基础上修复首轮测试发现的两个问题：
>
> 1. **Emby 设置页空白**：根因是 Emby 的配置页机制与 Jellyfin 不同——Emby 注入页面 HTML 后**不执行内联 `<script>`**，
>    逻辑必须放在 `data-controller` 指向的独立 AMD 模块里。已为 Emby 重写专属配置页
>    （`embyConfigPage.html` + `embyConfigPage.js`），Jellyfin 侧页面不动。
> 2. **Emby 插件无图标**：Emby 的插件列表图标不是 meta.json（那是 Jellyfin 的机制），而是读插件程序集内
>    `IHasThumbImage` 嵌入图。已嵌入 640×360 缩略图并实现该接口。
>
> 测试通过后随 EMBY 合并回 main，统一按 `main-v0.4.0` 正式发版。
